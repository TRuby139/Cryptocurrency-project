# Cryptocurrency-project
Frontend project that use fetch() and API call to fetch data
Core Functionality:

•	Allow users to search and track cryptocurrency data (e.g., by coin name or symbol such as BTC, ETH).

•	Display real-time and historical cryptocurrency price data using interactive charts (e.g., line charts, candlestick charts).

•	Implement a portfolio management module that allows users to record, track, and evaluate their crypto holdings, including profit/loss analysis.

•	Provide basic technical analysis indicators (e.g., moving averages, RSI, MACD, trading volume).

•	Include a cryptocurrency price prediction feature using machine learning or statistical techniques (e.g., linear regression).

•	Enable interactive chart tools such as:

a.	Zoom and pan capabilities for detailed chart analysis.


How to use it:
1. Download the file
2. Create an account at coingecko website
3. Click your account icon and click the Developer's Dashboard
4. Get an api key
5. Open script.js
6. Go to line 10 and find this code
7. const API_KEY = "enter your coingecko API key here";
